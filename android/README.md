# Android app text

`values/strings.xml` is a copy of the
[Android app's](https://github.com/otherworld-dev/Shopping-List-Android) English
text, kept here so it can be translated in the same Crowdin project as the web
app. Crowdin writes the translations to `values-<language>/`, and the Android
repo copies them back before each release. Don't edit these files by hand,
change the text in the Android repo instead.
